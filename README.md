# My Wall-Space

## КАК УСТАНОВИТЬ В СУЩЕСТВУЮЩИЙ ПРОЕКТ Ren'Py

Если у тебя уже есть проект `mw` в Ren'Py Launcher:

### Шаг 1 — Скачай ZIP
https://github.com/suxarickk/My-wall-space/archive/refs/heads/main.zip

### Шаг 2 — Скопируй файлы в mw\game\

Из архива `My-wall-space-main\game\` скопируй в твою папку `mw\game\`:

```
СКОПИРОВАТЬ:
✅ script.rpy        (заменить!)
✅ characters.rpy    (добавить)
✅ definitions.rpy   (добавить)
✅ prologue.rpy      (добавить)
✅ chapter_one.rpy   (добавить)
✅ папку images\     (добавить целиком)
✅ папку battle\     (добавить целиком)
✅ папку audio\      (добавить целиком)

НЕ ТРОГАТЬ (оставь как есть):
❌ options.rpy
❌ gui.rpy
❌ screens.rpy
```

### Шаг 3 — Запусти
В Ren'Py Launcher выбери `mw` → Перекомпилировать → Запустить проект
