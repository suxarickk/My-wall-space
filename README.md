# My Wall-Space

> Психологическая готическая визуальная новелла.

**Жанр:** психологическая готика + VN исследование + тактические бои  
**Движок:** [Ren'Py 8.x](https://www.renpy.org/) (Python 3)  
**Статус:** 🚧 В разработке — Пролог готов

---

## Персонажи

| Персонаж | Роль |
|---|---|
| **РАнфи** (РАнфэлл) | Главный герой, 16 лет |
| **ЛифАрсий** | Ангел-хранитель, говорит на лифарсийском языке |
| **ДжЕрмин** | Лучший друг РАнфи |
| **ИдзУки** | Программист, знает 15 языков |
| **БеззесЕлинт** | Загадочный персонаж из прошлого |

## Система единиц

- **Рост:** этрИции
- **Вес:** гуартАции / квертАции
- **Возраст:** дюбернИции (дни) / любернИции (годы)
- **Энергия:** Святые и Тёмные ЛЮмины (0–10 каждый)

## Запуск

### Требования
- [Ren'Py SDK 8.1+](https://www.renpy.org/latest.html)

### Шаги

```bash
# 1. Клонируй репозиторий
git clone https://github.com/suxarickk/my-wall-space.git

# 2. Открой Ren'Py Launcher
# 3. Add Existing Project → выбери папку my-wall-space
# 4. Launch Project
```

### Структура папок

```
game/
├── script.rpy          ← точка входа
├── characters.rpy      ← персонажи и статы
├── definitions.rpy     ← образы, трансформации
├── prologue.rpy        ← Глава 0: Пролог ✅
├── chapter_one.rpy     ← Глава 1 (в разработке)
├── options.rpy         ← настройки
├── battle/
│   └── battle_engine.rpy  ← система боя (Люмины, ACT)
├── images/
│   ├── bg/             ← фоны
│   └── sprites/        ← спрайты персонажей
└── audio/
    ├── music/          ← музыка (добавь .ogg файлы)
    └── sfx/            ← звуки
```

### Аудио (placeholders)

Добавь `.ogg` файлы в `game/audio/`:

| Файл | Описание |
|---|---|
| `music/night_ambient.ogg` | Тихий эмбиент, холодная ночь |
| `music/etarcius_dream.ogg` | Тревожная тема сна ЭтАрциуса |
| `music/main_menu.ogg` | Главное меню |
| `sfx/lifarsiy_arrive.ogg` | Появление ЛифАрсия |
